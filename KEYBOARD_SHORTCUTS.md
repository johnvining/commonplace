# Commonplace Keyboard Shortcuts

## 1. Global Shortcuts

Always available throughout the application.

### 1.1 Search Bar Toggle
| Shortcut | Action |
|----------|--------|
| `Ctrl+O` | Toggle search bar open/closed |
| `/` | Open search bar |
| `Ctrl+/` | Toggle keyboard shortcuts help |
| `?` | Toggle keyboard shortcuts help |
| `h` | Go home |
| `c` | Create a note |
| `d` | Cycle day / night / follow system |

Single-key shortcuts (`/`, `?`, `j`, `k`, `e`, `o`, …) are ignored while typing in a field.

### 1.2 View Mode Switching
| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+1` | Full view |
| `Ctrl+Shift+2` | Slim view |
| `Ctrl+Shift+3` | Grid view |
| `Ctrl+Shift+4` | Tile view |

---

## 2. Search Bar

Active when the search bar is open.

### 2.1 Navigation
| Shortcut | Action |
|----------|--------|
| `Escape` | Close search bar |
| `Backspace` | Return to previous modifier (when input empty) |

### 2.2 Execution
| Shortcut | Action |
|----------|--------|
| `Enter` | Execute current command |

### 2.3 Modifiers (Type to Activate)
| Prefix | Mode |
|--------|------|
| `auth` | Search/create authors |
| `find` | Full text search |
| `idea` | Search/create ideas |
| `list` | View lists |
| `note` | Create new note |
| `pile` | Search/create piles |
| `work` | Search/create works |
| `read` | Access reading page |

### 2.4 Direct Commands (Enter to Execute)
| Command | Action |
|---------|--------|
| `logout` | Log out |
| `flip` | Go to flip view |
| `home` | Go to home |
| `load` | Go to load page |
| `file` | Go to file list |
| `slim` / `full` / `grid` / `tile` | Switch view mode |

On the search results page, `[` / `]` page through results and `v` opens the notes among them for tagging.

---

## 3. Entity Pages

Shortcuts for Author, Work, Pile, Idea, and Read pages.

### 3.1 Common Entity Shortcuts
Available on all entity pages (Author, Work, Pile, Idea, Read).

| Shortcut | Action |
|----------|--------|
| `Ctrl+E` | Edit entity details |
| `Ctrl+A` | Save changes (when editing) |
| `Ctrl+S` | Star/unstar entity (when not editing) |
| `#` | Delete the entity (asks first) |
| `Escape` | Exit edit mode |

### 3.2 Author Page
| Shortcut | Action |
|----------|--------|
| `Ctrl+S` | Star / unstar author |
| `v` | Show the author's notes |
| `b` | Back to the author (from their notes) |

### 3.3 Work Page
| Shortcut | Action |
|----------|--------|
| `Ctrl+N` | Create new note for this work |
| `Ctrl+P` | Edit piles |
| `Ctrl+T` | Edit ideas |
| `r` | Read |
| `i` | Import notes (`Ctrl+Enter` finishes) |
| `Ctrl+U` | Upload images as notes |

### 3.4 Read Page
| Shortcut | Action |
|----------|--------|
| `Ctrl+N` | Create new note for this work |

### 3.5 Pile Page
| Shortcut | Action |
|----------|--------|
| `Ctrl+N` | Create new note in this pile |
| `v` | View notes / view all |
| `f` | Narrow (filter by this pile) |

### 3.6 Idea Page
| Shortcut | Action |
|----------|--------|
| `f` | Narrow (filter by this idea) |
| `Ctrl+N` | Create new note with this idea |

## 4. Note List

Shortcuts for navigating and selecting notes. **Only works in Full view mode.**

### 4.1 Selection
| Shortcut | Action |
|----------|--------|
| `j` | Select next note (past the last one: next page) |
| `k` | Select previous note (before the first one: previous page) |
| `Enter` | Select focused note; on the selected note, open it |
| `Escape` | Deselect note |
| `e` | Edit selected note |
| `o` | Open selected note on its own page |
| `[` / `]` | Previous / next page (any view) |

### 4.2 Quick Edit (With Note Selected)
| Shortcut | Action |
|----------|--------|
| `Ctrl+E` | Edit note content |
| `Ctrl+T` | Edit tags/ideas |
| `Ctrl+P` | Edit piles |
| `Ctrl+L` | Add links |
| `Ctrl+S` | Star/unstar selected note |
| `y` | Copy the note's nick |
| `m` | Show more of a long note |
| `#` | Delete the note (asks first) |

---

### 4.3 Selecting Notes (Slim, Grid and Tile Views)
| Shortcut | Action |
|----------|--------|
| `x` | Select / unselect the focused note |
| `*` | Select all / none |
| `#` | Delete the selected notes |
| `Ctrl+T` / `w` / `@` / `Ctrl+P` | Add an idea / work / author / pile to them |
| `Ctrl+R` | OCR them |
| `Ctrl+S` | Suggest titles for them |
| `y` | Copy them as a list |
| `Escape` | Unselect all |

---

## 5. Note Editing

Shortcuts when editing a note in Full view.

### 5.1 Save and Exit
| Shortcut | Action |
|----------|--------|
| `Ctrl+A` | Save changes |
| `Escape` | Exit edit mode (discard unsaved) |

### 5.2 Text Tools (Edit Mode Only)
| Shortcut | Action |
|----------|--------|
| `Ctrl+U` | Upload images |
| `Ctrl+M` | Show fewer / all fields |
| `Ctrl+F` | Format text (remove extra whitespace) |
| `Ctrl+S` | Generate AI title suggestion |
| `Ctrl+R` | Run OCR on images |

### 5.3 Image Navigation
| Shortcut | Action |
|----------|--------|
| `z` | Zoom the image open in the reader |
| `Ctrl+I` | Open/close the image reader: the image beside the note's text (Esc closes; click the image to zoom) |
| `←` / `Ctrl+J` | Previous image (opens the last one if none is open) |
| `→` / `Ctrl+K` | Next image (opens the first one if none is open) |

The arrow keys only act on a note that has images.

### 5.4 Note Links Mode
| Shortcut | Action |
|----------|--------|
| `Enter` | Add typed nick as link |

When autocomplete dropdown is visible.

## 7. Flip

On the flip (review) page, when not typing in a field.

| Shortcut | Action |
|----------|--------|
| `1` | Fast: see this card again within a week |
| `2` | Med: see it again in 1 to 6 months |
| `3` | Slow: see it again in 6 to 18 months |
| `n` | Next card, without rating this one |
| `Enter` | Deal again (when the deck is done) |
| `p` | Previous card |

Each card starts selected, so the note shortcuts (`Ctrl+E` to edit, etc.) work right away. Flip keys are ignored while a note is being edited.

---

## 8. Other Pages

| Page | Shortcut | Action |
|------|----------|--------|
| Load | `Ctrl+Enter` | Submit the import |
| Load | `Escape` | Cancel a running import |
| Maintenance | `Shift+D` / `Shift+R` | Dry run / run the next task (Enter confirms, Escape cancels) |
| Login | `Enter` | Log in |

In idea and pile pickers, `Backspace` in an empty field removes the last one and `Ctrl+S` asks for AI idea suggestions.
